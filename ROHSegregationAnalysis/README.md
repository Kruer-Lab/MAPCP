These codes help with performing ROH segregation between affected and unaffected family members. The R script can be run using the main shell script (ROHSegregationAnalysisSettings.sh). 
- All inputs, specifying affected and unaffected members, must be updated in ROHSegregationAnalysisSettings.sh
- If any prerequisite packages are missing, the script will try and install them from CRAN
- Please make necessary adjustments to the shell script if running the code in hpc environment
